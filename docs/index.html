Mago for VS Code

PHP static analysis, right where you write code. Lint, analyze, format, and manage baselines without leaving your editor — powered by Mago.

Install from Marketplace View on GitHub

Features

Lint & Analyze

Run Mago's lint and analyze commands on a single file or the whole project, with results reported straight into VS Code.

Format PHP Files

Format your code with Mago's formatter, including optional format-on-save.

Baseline Support

Suppress existing issues with baseline files so you can focus on what's new — ideal for legacy codebases.

Problems Pane Integration

All detected issues appear in VS Code's native Problems pane with collapsible details.

Auto-run on Save

Automatically lint, analyze, and format files whenever you save, with each behavior independently configurable.

Command Palette

Access every Mago command directly from VS Code's command palette — no context switching required.

Get Started

  1. Install Mago and make sure it's available on your PATH (or set mago.executablePath).
  2. Install the extension from the VS Code Marketplace.
  3. Open a PHP file — lint and analyze run automatically on save.
  4. Check results in the Problems pane (View → Problems).
